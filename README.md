## 📊 Dataset and Instruction Generation

Unlike prior approaches, we do not rely on visual features as the intermediary for aligning fine-grained pronunciation duration and emotional cues in dubbing with the video. Instead, we leverage natural language instructions generated by a multimodal large language model to achieve fine-grained alignment.

We adopt [LLaVA-NEXT-7B](https://github.com/LLaVA-VL/LLaVA-NeXT) as the multimodal large language model for instruction generation, and the generated raw instructions are provided in the Instruction folder. Below we provide the prompt we use:

For emotion instruction:
```
The character's script is [The Dubbing Script]. Based on the script and changes in the character's mouth movements in the video, what is the speaking pace? If there are variations in the pace, please describe the trend of these changes.
```

For speaking rate instruction:
```
The character's script is [The Dubbing Script]. Please analyze the emotional changes of the characters in this video base on the video content and the script
```

Subsequently, we employ a Global Text Encoder (GTE) [Qwen2-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2-1.5B-Instruct) to convert the natural-language alignment instructions into textual representations, which are then used for model training.

Everyone are free to experiment with other multimodal large language models or alternative text encoders. We here provide the processed textual features of the three datasets used in our implementation:

- V2C-Animation benchmark: [BaiduDrive](https://pan.baidu.com/s/1ms8SOOE8R65Si234K3OuEA) (Password: x7in) / [GoogleDrive]()(WIP)

## 🔧 Training

You need to modify the ```data_params```, and related configuration, then define your experiment name ```exp_name``` in the configuration file before starting training. There will be a diretory same as your ```exp_name``` in the ```output``` .

The pretrained acoustic checkpoint are provided as below, please download and replace the path in ```first_stage_path```:

- First Stage Checkpoint: [Baidu Drive](https://pan.baidu.com/s/1ZUAjOu4jTkx0znVMBngVKA) (b5wy), [Google Drive](https://drive.google.com/file/d/1HF1Bh44oO8w2EYOfX0H6ZhUHVFhMRJOG/view?usp=drive_link).

For V2C-Animation Benchmark：
```
python train_second_instruct.py -p Configs_Instruct/config_denoise.yml
```
For Chem Benchmark:
```
python train_second_instruct.py -p Configs_Instruct/config_Chem.yml
```
For GRID Benchmark:
```
python train_second_instruct.py -p Configs_Instruct/config_grid.yml
```

## ✍ Inference (WIP)

Since the inference is ralated to other 2 MLLMs, the inference usage is work in progress. The emotion instrcution features provided upon is the ground truth emotion entities of the dubbing audio, it can not directly used for inference, only to examine the performance upper bound of the Instructed Emotion Calibration.

For checkpoints trained on V2C-Animation benchmark and dubing the video from V2C-Animation benchmark (In-domain dubbing):
```
python inference_v2c_instruct.py -n  --epoch 30 --setting V2C
```
For checkpoints trained on V2C-Animation benchmark and dubing the video from Chem benchmark (Zero-shot dubbing V2C2Chem):
```
python inference_v2c_instruct.py -n  --epoch 30 --setting Chem
```
